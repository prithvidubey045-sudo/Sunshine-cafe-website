# ☀️ Sunshine Cafe & Restaurant - Official Dine-In Website

Welcome to the official repository for **Sunshine Cafe & Restaurant**, Pithora's favourite dine-in destination for handcrafted culinary dishes, aromatic coffee, and cozy family vibes!

---

## 🌟 Key Features

* **Warm Cream & Coffee Aesthetic**: Responsive UI featuring a warm cream background, coffee brown typography (`#2c1e16`), and vibrant orange accents (`#E67E22`).
* **Scroll-Triggered Glassmorphism Navigation**: Floating frosted glass navigation bar (`backdrop-filter: blur(18px)`) on scroll.
* **Streamlined Homepage Menu**: Displays 6 featured dishes with quick category filters (`All`, `Veg`, `Non-Veg`, `Pizza`, `Chinese`, `Shakes`).
* **Digital Menu Book Modal**: Fullscreen interactive menu popup covering all **19 official Sunshine Cafe categories**.
* **Dine-In Focus**: Pure restaurant menu layout (zero e-commerce/shopping cart bloat) with direct **"Reserve Table"** and **"Chat on WhatsApp"** actions.
* **Continuous Infinite Review Slider**: Seamless guest review marquee animation that pauses smoothly on mouse hover.
* **Exact Location Google Map**: Pinpoint interactive map centered on Sunshine Cafe, Lahrod Chowk, Pithora (`z=18` zoom level).
* **Light / Warm Dark Theme Toggle**: Light mode default with persistent warm espresso dark theme saved in `localStorage`.
* **Fullscreen Lightbox Gallery**: Interactive photo viewer with touch swipe and keyboard navigation.

## 🚀 Running Locally

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/prithvidubey045-sudo/Sunshine-cafe-website.git
   cd Sunshine-cafe-website
   ```

2. **Start Local Server**:
   ```bash
   npm start
   # or run using Python:
   python -m http.server 8080
   ```

3. **Open in Browser**:
   Navigate to `http://localhost:8080` in your web browser.
